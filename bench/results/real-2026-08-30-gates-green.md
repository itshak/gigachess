## What was fixed to get here

1. **Castling (perft 220 mismatches → 0; dests-terminal 6 → 0).** One shared
   `detectCastling`/apply path now serves `makeMove`, `isLegal`, `parseSan`,
   `makeSan`, and the internal perft movegen (design D2). Root causes fixed:
   (a) `makeMove` with a normalized castling dest moved only the king;
   (b) `destsFast`/`genLegalMoves` misclassified ANY king step to
   `{g,c}1/{g,c}8` as castling whenever ANY color held rights, corrupting the
   legality scratch board via fallback rook placement; (c) `makeSan` rendered
   canonical castling as `Kg1`. Representation decided by bake-off
   (`bench/castling-bakeoff.mjs`): **king-captures-rook** (`e1h1`) —
   measurements and the UCI engine boundary in ADR-013 as amended.
   `tests/castling.mjs` locks the minimal repros (kiwipete d4 = 4,085,603;
   `r3k2r/…b kq` queenside → `2kr3r/…`, kingside → `r4rk1/…`; `makeSan`
   `O-O`; the replayed-position repro `r2kQb1r … b KQ - 2 13`).
2. **En-passant FEN parity (470 rejections → 0).** `parseFen` accepts
   structurally valid ep squares regardless of capturability
   (chessops-compatible) and round-trips byte-identically; `strict: true`
   restores the capturable check (`fen/enPassantNotCapturable`, en/ru/he).
   Four-field FENs (WAC corpus) parse with chessops-compatible defaults —
   required for the perft suite's 150 WAC FENs to parse at all.
3. **SAN make 100% (was 99.99%).** `makeSan` now detects an en-passant capture from the position (pawn moving diagonally onto the empty ep square) instead of requiring the `isEnPassant` flag — external move objects without the flag rendered `hxg3` as the quiet push `g3` (6 diffs over the full corpus, all this class).
4. **FEN throughput (0.97–1.06× → 2.022×).** `parseFen` builds the board in a
   single scratch pass (one immutable copy instead of 32 per-piece board
   clones) with inline piece decoding; `makeFen` emits the placement field via
   direct bit tests instead of 64 `pieceAt` calls.
4. **Magic tables as gzip+base64 blobs, lazily loaded (81 KB → 47 KB gz
   total; core static free of table bytes).** Generated by
   `bench/magic-tables/generate-blob.mjs` (gzip -9 + base64), decoded into
   `Uint32Array` lo/hi views via `DecompressionStream` behind
   `ensureMagicTablesLoaded()`; the naive ray-walk fallback serves until load
   completes (1.63× chessops) and each call returns a fresh `{lo, hi}` (the
   old object table handed out shared mutable entries — ADR-012 hazard).
   Loaded magic is 3.36× chessops (35.5 MAttacks/s), consistent with the
   design-phase measurement (35.1).
5. **genLegalMoves hot loop** rewritten with allocation-free LSB bit
   iteration (no per-piece closures, hoisted promotion array) — required for
   the perft speed gate after unifying castling detection (baseline was
   already 0.94× chessops on Kiwipete; now +19.0% on the full corpus).
