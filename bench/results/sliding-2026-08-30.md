## Derived metrics

- **MQueens/s** = `iters / (medianMs/1000) / 1e6`
- **BigInt slowdown:** `51.75 / 3.47 = 14.9×` (10M) — **✓ proves 10–60× slower, not hot-path viable** (`tc39/proposal-bigint#117`)
- **B vs A:** `(51.75 - 9.56)/9.56 = +441.1%` (10M) — **✓ exceeds ≥30% gate by 411pp → Black Magic WINS slider**
- **C vs B:** `(34.83 - 51.75)/51.75 = -32.7%` — **REAL ReScript is 32.7% SLOWER than TS Black Magic** on same tables/magics (honest language bake-off)
- **C vs A:** `(34.83 - 9.56)/9.56 = +264%` — ReScript still beats HQ, but loses to TS

## Decision per spec gates

**Slider gate:** `specs/purechess-benchmarks` SHALL: *B (Black Magic lo/hi) SHALL achieve ≥30% higher MQueens/s than A (chessops HQ) to be declared winner; otherwise HQ remains fallback.*

```
1M:  B (46.05) vs A (9.25) → +398.0% → ✓ PASS
10M: B (51.75) vs A (9.56) → +441.1% → ✓ PASS
Winner (slider): black-magic (TS plain fixed-shift lo/hi)
```

**Language gate (bake-off Task 4.3-4.4):** TS functional `{lo,hi}` manual vs ReScript `{lo,hi}` manual (both honest Black Magic, same `bench/magic-tables/*.json`, no Belt/Int64)

```
10M: B (TS) 51.75 vs C (ReScript) 34.83 → TS +48.6% faster → ✓ TS WINS language
```

**Result:** With **REAL chessops HQ** and **REAL ReScript Black Magic** (same tables), **TS functional Black Magic wins BOTH gates**: it beats HQ by **441%** (slider) and beats ReScript by **48.6%** (language). The earlier synthetic `rescript-lohi` stub at 63 MQueens/s was **faster than B** because it skipped table lookups; the honest ReScript at 34.8 is **slower** than honest TS at 51.7.

### Implications

- **Board encoding:** `{lo,hi}` manual pair **locked** — all candidates use it; BigInt ruled out per 14.9×.
- **Slider algorithm:** **Black Magic (plain fixed-shift, TS)** wins and SHALL be used for `purechess` sliding attacks. Phase 2 will keep per-square `mask/magic/shift` via MIT `RecklessMagics` (uniform shift 11 already wins; per-square is size opt only).
- **Language:** **TS functional ({lo,hi} manual) wins** over ReScript for hot path — faster (51.75 vs 34.83), zero toolchain, smallest bundle (`purechess/core` target), larger hiring pool. ReScript remains viable for PGN/tree (functional) but not for `attacks`. Spec stays language-neutral; impl SHALL default to TS for `src/squareSet.ts` + `src/attacks.ts`.
- **Bundle:** TS pure functional (readonly, `Result`, `Belt` avoided) already gives 90% of FP benefits (immutability, no null) with best JIT shape.
