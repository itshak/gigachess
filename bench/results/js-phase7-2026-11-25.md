# Phase 7: independent compact perft state (2026-11-25)

## Result

On aiserver (Xeon E5-1620 v2), the pure-JS standard perft prototype
eliminates the deep-perft deficit. It beats the exact published drumevp
1.3.2 package on all five perft workloads in nine rotated rounds under
Node 24.13.0, and in independent 11-round runs on Node 24.19.0, Node
22.5.0 and Bun 1.4.0 (JavaScriptCore). See raw JSON for all wall and CPU
samples, not just medians. One physical CPU only; no browser/ARM claim.

## Implementation

- Retain independently verified Phase 6 king-safety role-mask reuse.
- Convert standard-chess Board into 12 color/role bitboards, 3
  occupancy bitboards, king squares, EP and castling rights. State and
  move buffers are per ply, independent of public Board mutation.
- Count legal leaves directly; fused checker/pin classification,
  parallel unpinned pawns with check mask, exact EP and standard castling.
- Internal flags are not public moves2 encoding. Chess960, cold magic,
  depth-one and unusual/malformed states keep the ordinary path.
- No runtime dependency, WASM, native code or competitor code copied.
- New test executes compact path directly, reports active/fallback cases,
  compares independently with chessops at depth 3, and verifies both
  package entry points and complete public state restoration.

## Correctness

Full npm test passed, including 1,000 seeded games, 118,380 plies,
11,684 undos, 380 frozen order fixtures and 114 standard/Chess960
state-restoration checks. Additional 9,933 positions (415 checks) and
571 depth-three positions (295 random, 276 corpus, 571 active compact
paths, zero fallbacks in this valid corpus), 1,142 entrypoint checks.
Full competitive correctness: 20 reference, 276 corpus, zero
mismatches or skips. Four extra deep fixtures each independently
verified against chessops, source and npm package. npm pack dry run
passed. New differential test is included in npm test.

## Still open

A separate standard direct movegen experiment passed 10,178 positions
against the prior exact order and chess.js, including 360 checks,
43 EP targets and 369 castling moves. It improved fresh generation
from 48,937/s to 108,598/s in an 11-round direct benchmark, but published
drumevp remained at 177,110/s (source 163,566/s). A smaller default
typed-array/cached-checker variant regressed and is not retained.
Further movegen prototypes and exact magic multiplication tests are
isolated on the server, not part of this runtime commit.

The Phase 6 general diagnostic passed 23/24 gates; loaded magic
throughput missed its 2.4x chessops target. The pinned-runtime broad
benchmark is a separate release gate and must not be assumed green.
